# UAT Feedback Template

For each scenario record the user, scenario id, date, and these questions.

## Task result

- Task completed? PASS / PARTIAL / FAIL
- Time to complete:
- Interactions/backtracks:
- Errors encountered:
- Developer help needed?

## Understanding

- What did the product tell you?
- What was missing or ambiguous?
- Which number or label did you distrust, and why?
- Was research vs current market state clear?
- Was blocked vs unavailable clear?

## Evidence and provenance

- Could you see source, freshness, assumptions, constraints, and calculation?
- What evidence would you show a reviewer?
- Was the review boundary (decision support, no execution) clear?

## Daily usefulness

- Would you use this in daily work? Why/why not?
- What single change would improve trust most?
- What felt like unnecessary work?
- What terminology confused you (EN/zh)?
