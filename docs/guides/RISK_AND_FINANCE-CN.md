# 风险、中后台与财务使用指南

[English](RISK_AND_FINANCE.md) · [客户使用指南](README-CN.md)

先选择账簿、估值日期和报告币种，再核对系统纳入的头寸、估值及限额例外。

## 核对风险敞口

1. 打开“组合”的敞口视图和头寸阶梯。
2. 确认账簿范围、交付期限、实物合同及导入的交易腿。
3. 按枢纽和交付月查看净头寸及套保指标。
4. 阅读汇总前，先检查未估值头寸、缺失汇率及估值警告。
5. 抽取合同和交易，与公司的头寸管理系统核对。

**完成后：**复核结果说明纳入了哪些头寸，以及存在哪些例外。按地区或业务分组属于分析汇总；访问边界由安装环境的权限和实际支持的数据范围控制。

## 理解估值价格

月度曲线优先使用月度报价，并根据较长交付产品构建其他月份。权重按交付小时数计算，包含夏令时切换的影响。头寸视图还可能对曲线未覆盖的月份采用该枢纽最近日收盘价，并将方法标为平价沿用（flat）。

复核时，应区分直接报价、推导价格和平价沿用。曲线没有覆盖某个月份，与头寸视图随后补用估值价格，是两个不同步骤。

参考性 VaR 根据系统纳入头寸的历史价格变动计算。结合页面显示的期限、置信水平、样本历史和警告阅读结果；气量不确定性、形状、基差和信用风险分别评估。

详见[计算口径](../user/DATA_STATUS_AND_PROVENANCE-CN.md#计算口径)。

## 检查授信和交易授权

1. 在敞口视图中打开授信与交易授权功能。
2. 核对交易对手映射、获批额度、抵押担保、审批到期日和使用率。
3. 按账簿、枢纽、期限及允许的工具检查交易员授权。
4. 查看适用的合同级套保审批。
5. 按公司的控制流程记录例外、责任人和后续处理。

使用获授权的风险控制功能修改审批，并与公司留存的限额记录核对，保存审计关联编号。[风险图文参考](../user/manual/RISK.md)介绍相关表单。

## 核对现金与融资条款

查看各合同的币种、付款日期或账期，以及已记录的融资条款。检查所选计算支持的基准利率、利差、计息天数规则和估值日。年化百分比与每日现金金额属于不同指标。

资源池比较应逐项检查合同利率或情景默认利率，以及计息基准。合同利率缺失时的默认规则见[组合比较与头寸复核](../user/PORTFOLIO_WORKFLOW-CN.md)。[利率来源](../operations/INTEREST_RATES.md)说明可用的基准输入。

## 保存复核记录

保留允许导出的头寸视图及其上下文，列明未纳入或未估值的交易腿，并关联决策和审计记录。公司的风险管理系统和财务账簿提供控制及会计流程所用的核对记录。
