# 法务与合规使用指南

[English](LEGAL_COMPLIANCE.md) · [客户使用指南](README-CN.md)

本节介绍如何查找决策依据、复核权限分配，以及检查授权数据的使用范围。

## 查阅一项决策

1. 打开“决策中心”>“复核”，选择所需事项。
2. 查看目标、发起人、分析上下文和关联依据。
3. 检查假设、警告、来源引用和已记录的结论。
4. 核对复核人身份，以及发起人与复核人的职责分离。
5. 保存事项编号和相关审计编号。

**完成后：**可以说明由谁复核了哪些信息，以及记录了什么结果。交易执行与结算记录从公司对应系统获取。

## 复核数据授权

向数据管理员获取当前许可登记和用户数据范围分配。按公司的供应商协议核对来源类别、允许用途、有效期、办公室及实名用户条件，并覆盖数据导出、衍生数据集和外部接收人的使用。

保存 API 凭据用于技术连接；许可和访问记录用于确认获授权的用户及用途。

## 检查账户与留存安排

1. 与权限负责人确认普通用户及特权账户的复核范围。
2. 将角色和数据范围与获批申请核对。
3. 使用获授权账户，在“管理”>“访问与身份”的审计页查看相关变更。
4. 与运营人员核对该环境实际采用的留存设置及公司要求。
5. 抽查一份记录能否检索，并保存复核结果。

进一步资料：[身份与单点登录](../operations/ENTERPRISE_SSO.md)、[角色与职责](../product/ROLES_AND_RESPONSIBILITIES.md)、[合规评估](../compliance/COMPLIANCE_AUDIT.md)。可配置的留存期限应与该环境的实际政策核对。

## 检查 AI 辅助分析

确认安装环境使用的模型服务、外部调用政策、允许输入的信息，以及回答所关联的记录。使用 AI 解释时，保留原分析记录及复核人的判断。

数据、权限和支持安排在[上线交接记录](CLIENT_ONBOARDING-CN.md)中登记。按公司的实际业务与安装环境落实监管及合同要求，将相关审批保存在交接记录中。
