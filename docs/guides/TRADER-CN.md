# 交易员使用指南

[English](TRADER.md) · [客户使用指南](README-CN.md)

本节介绍开盘前检查、头寸核对以及销售和运输方案比较。开始前，准备好相关账簿、交付期和交易台采用的价格来源。

## 做好市场检查

1. 打开“市场”>“曲线与价差”，选择气日、交付产品和枢纽。
2. 比较不同枢纽时使用枢纽报价板；按产品查看市场时使用报价阶梯视图。
3. 查看买卖价、来源和更新时间。比较 NBP 的 p/th 与欧洲大陆枢纽的 EUR/MWh 时，先统一口径。
4. 打开“容量与事件”，查看流量、容量、储气、LNG 及已发布的停运信息。
5. 查看与你的头寸有关的告警，并追查异常对应的数据来源。

**完成后：**形成覆盖同一交付期的市场判断。时间、参考价格及汇率口径见[数据说明](../user/DATA_STATUS_AND_PROVENANCE-CN.md)。

## 核对实物组合

1. 在“组合”中打开资源或合同列表。
2. 查看合同记录的交付点、合同气量、价格币种、付款条款和容量权利。
3. 已接入相关记录时，检查每日气量平衡及实际交付量与提名量（nomination）的差异。
4. 打开敞口或头寸视图，按枢纽和交付月核对账簿、实物与金融交易腿、估值价格和套保指标。

**完成后：**头寸判断能够对应到合同与导入的交易记录。[交易员图文参考](../user/manual/TRADER.md)介绍合同录入、PDF 条款读取、终止和恢复操作。

## 比较路径与销售方案

1. 打开“组合”的路径视图，检查候选方案的成本、容量和使用权。
2. 使用情景分析入口，将所选方案带入“决策中心”。
3. 确认比较采用哪些已保存的资源和销售选项。面板中的临时修改与已保存合同在计算中可能承担不同作用。
4. 运行对比或优化，检查已分配与未分配气量、约束、价格和汇率口径，以及融资假设。
5. 保存方案及分析依据，提交复核。

**完成后：**可以解释各方案的气量、成本和关键假设。计算受阻时，先处理结果列出的输入或约束；没有结果时检查数据和配置，不能直接推断为收益为零。

每份资源优先采用自身合同已记录的融资利率；资源未记录利率时，才采用情景默认值。界面默认值取自第一份已保存上游合同，或在其缺失时取草稿值。比较不同融资条款时，逐项查看分配结果采用的利率、来源和计息基准。详见[组合比较与头寸复核](../user/PORTFOLIO_WORKFLOW-CN.md)。

## 保存复核结果

打开“决策中心”>“复核”，查看备选方案，使用获授权的操作记录结论和理由。后续交易或运营指令通过公司的既有审批和执行流程办理。

## 保持报价可追溯

授权行情通过公司的数据连接或获批导入流程进入系统。数据源出现在目录中，表示已登记该来源；实际接入的数据集及最近成功更新时间，应由数据运营人员确认。

参阅[行情接入与导入](../operations/LIVE_PRICE_SOURCES.md)及[技术支持](SUPPORT_AND_UPDATES-CN.md)。
