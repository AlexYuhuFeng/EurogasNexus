# 研究与量化分析指南

[English](ANALYST_QUANT.md) · [客户使用指南](README-CN.md)

本节的目标是保留足够的输入、版本和参数，使另一位获授权同事能够复现分析结果。

## 先研究一个价差

1. 打开“策略实验室”的价差分析页。
2. 选择序列和权重，检查每条腿的枢纽、交付产品、来源、单位和历史覆盖范围。
3. 组合序列前，统一币种和能量单位。
4. 查看选定期间的价差走势及统计指标。
5. 运行规则回测时，同时记录规则、样本区间和成本假设。

**核对结果：**输入序列及区间能够解释本次采用的观测数据。序列缺失或历史较短会改变样本，对比不同运行前应先处理这些差异。操作细节见[价差与策略流程](../user/STRATEGY_LAB.md)。

## 将研究保存为策略

1. 在设计页创建或选择策略，完成草稿。
2. 处理校验阻塞项，再冻结版本以保留当时的策略定义。
3. 打开回测页，选择期间和评估规则并运行。
4. 查看收益、回撤、归因、警告和数据覆盖。
5. 在对比页选择可比较的已保存运行，阅读兼容性结果。
6. 通过影子监测，按指定基准和后续到达的数据评估冻结版本。

**核对结果：**保留策略版本和运行编号，同时记录输入期间及成本。修改冻结定义时，创建新的草稿版本。

## 构建研究数据集

1. 打开“系统”>“研究数据”的数据集页。
2. 选择已登记的目标、特征、实体和观察窗口。
3. 设置重采样及历史回看等选项，校验定义。
4. 校验通过后构建快照。
5. 导出前查看覆盖情况、时间完整性和训练准备度检查。

在研究笔记或模型记录中保存快照编号、数据集定义、观测类型及信息可获取时间截点。区分预测批次与实际观测，并说明缺失值处理方法。

技术资料：[时点数据集](../research/POINT_IN_TIME_DATASETS.md)、[特征](../research/FEATURE_REGISTRY.md)、[目标](../research/TARGET_REGISTRY.md)、[训练准备度](../research/ML_READINESS.md)。

## 在 Python 中使用

使用该安装环境配套的 SDK 和身份验证方式。从[SDK 说明](../../packages/python-sdk/README.md)和[函数目录](../api/DATA_SCIENCE_FUNCTIONS.md)开始，记录 API 地址、SDK 版本、请求参数和返回的来源信息。

直接采用对应 SDK 版本中的示例。界面上的功能名称不一定等于 Python 方法名。

## 向交易台分享研究

在决策事项或研究记录中附上运行或快照编号，并说明业务问题、假设和重要敏感性。分享前确认原始数据的授权范围、导出用途及接收人。
