# 客户上线与交接

[English](CLIENT_ONBOARDING.md) · [客户使用指南](README-CN.md)

按已约定的安装环境和运行范围准备交易台上线。部署负责人将完成的客户交接记录保存在公司批准的文档库。

## 一、明确服务安排

| 登记内容 | 负责人 |
| --- | --- |
| 环境名称、服务网址、版本、发布通道、构建及数据库结构版本 | 部署负责人 |
| 交易台、账簿、枢纽范围、业务用户及验收负责人 | 交易台负责人 |
| 登录方式、权限审批人及管理员 | 权限负责人 |
| 所需数据集、来源范围、许可和预期更新频率 | 数据负责人 |
| 客户端与设备版本，以及实际安装测试结果 | IT 负责人 |
| 支持联系人、服务时间、事件级别及升级渠道 | 服务负责人 |
| 备份频率、恢复目标、恢复测试结果及变更窗口 | 运营负责人 |

交接前填写本环境的实际安排。服务和恢复目标由客户确认，并作为该安装环境的交接字段登记。

## 二、接通账户与数据

1. 按[部署说明](../deployment/DEPLOYMENT_ROLES-CN.md)安装获批的服务器和客户端版本。
2. 配置登录方式，落实已批准的角色、岗位资料和数据范围。
3. 接入或导入所需数据，完成各来源的激活检查。
4. 确认首次刷新成功，并从每个关键数据集中抽查一条记录。
5. 设置组织默认偏好，确认业务日历和显示口径。

来源配置见[管理与数据运营](ADMIN_AND_OPERATIONS-CN.md)，核对方法见[数据口径](../user/DATA_STATUS_AND_PROVENANCE-CN.md)。

## 三、完成代表性验收任务

| 参与人员 | 验收任务 | 保留材料 |
| --- | --- | --- |
| 交易员 | 按共同口径比较两条价格，查看合同、头寸及路径方案 | 上下文、来源时间和保存的关联编号 |
| 分析人员 | 运行已保存分析或回测，检查数据集快照 | 版本、运行或快照编号及覆盖范围 |
| 风险复核人员 | 核对样本头寸，检查一项限额或审批 | 纳入范围、例外及复核记录 |
| 管理员 | 检查允许与受限访问，测试来源失败和重试 | 角色、数据范围及实际结果 |
| 运营人员 | 验证备份恢复和更新回退流程 | 测试日期、版本、数据库结构及结果 |
| 服务负责人 | 提交并转交一份测试支持报告 | 工单及实际接收团队 |

按约定范围选择任务。逐项登记通过、存在问题或延期，注明责任人和重要问题的解决结果。[发布就绪记录](../release/RELEASE_READINESS.md)保存版本层面的审批依据，客户交接记录保存具体安装环境的验收结果。

## 四、完成交接

向用户提供[首次使用指南](../user/QUICK_START-CN.md)、岗位指南和支持渠道。通过获批渠道向运营团队交接部署配置参考、来源计划、恢复手册和发布包清单。

记录交付版本、验收范围、未完成事项、验收负责人和交接日期。安排后续权限及数据质量复核，并明确谁负责版本更新。
