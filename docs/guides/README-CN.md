# Eurogas Nexus 客户使用指南

[English](README.md)

从日常任务开始使用 Eurogas Nexus：查看欧洲天然气市场、分析实物与金融头寸、比较经营方案，并保存决策依据。

## 第一次使用

1. 按照[首次登录与基础检查](../user/QUICK_START-CN.md)完成登录和数据核对。
2. 在下表中选择与你工作相关的指南。
3. 需要核对数值时，查看[数据口径与计算说明](../user/DATA_STATUS_AND_PROVENANCE-CN.md)。
4. 遇到访问、数据或页面问题，按照[技术支持与版本更新](SUPPORT_AND_UPDATES-CN.md)处理。

| 工作内容 | 使用指南 | 完成后应得到的结果 |
| --- | --- | --- |
| 交易及实物组合管理 | [交易员](TRADER-CN.md) | 有价格口径和假设说明的市场或组合分析 |
| 研究及量化分析 | [研究与量化](ANALYST_QUANT-CN.md) | 可复现的分析、策略运行或数据集快照 |
| 风险管理、中后台及财务 | [风险与财务](RISK_AND_FINANCE-CN.md) | 列明估值及控制例外的头寸复核 |
| 交易台及业务管理 | [管理层](MANAGEMENT-CN.md) | 组合概况、待处理事项及责任人 |
| 法务及合规 | [法务与合规](LEGAL_COMPLIANCE-CN.md) | 可追溯的决策和权限记录 |
| 系统管理及数据运营 | [管理与数据运营](ADMIN_AND_OPERATIONS-CN.md) | 可用的访问权限、数据连接和更新监控 |
| 新客户实施或交易台上线 | [客户上线与交接](CLIENT_ONBOARDING-CN.md) | 明确范围、责任人和验收结果的交接记录 |

## 找到所需功能

| 工作区 | 主要内容 |
| --- | --- |
| 市场 | 总览、曲线与价差、网络、容量与事件 |
| 组合 | 资源和合同、路径、头寸及风险敞口 |
| 策略实验室 | 价差研究、策略设计、回测、对比和影子监测 |
| 决策中心 | 情景分析、资源池优化及复核 |
| 系统 | 研究数据、智能体研究、设置、使用手册和术语表 |
| 管理 | 数据源中心、运行状态、访问与身份 |

你能看到的工作区由访问权限和岗位资料决定。岗位资料用于组织界面；角色和数据范围决定可查看的信息及可执行的操作。详见[角色与职责](../product/ROLES_AND_RESPONSIBILITIES.md)。

打开“系统”>“设置”可调整语言、外观和个人显示偏好。账户菜单也会打开同一设置页，并提供退出登录入口。使用键盘时，可按 Ctrl+K 打开搜索；支持的平台也可使用 ⌘K。触屏设备可直接点按搜索入口。

## 版本与使用范围

本指南依据 2026 年 11 月 5 日核对的 0.7.0 源码行为编写。实际可用功能、平台和发布状态，以公司交付的版本为准；在[上线交接记录](CLIENT_ONBOARDING-CN.md)中登记该版本。

系统用于分析和决策记录。交易执行、提名申报和结算处理沿用公司的交易及运营系统。[发布就绪记录](../release/RELEASE_READINESS.md)保存发布审批依据，[更新日志](../../CHANGELOG.md)说明版本变化。

[图文操作参考](../user/manual/README.md)使用示例数据展示操作过程。[技术文档索引](../README-CN.md)提供部署、API 和方法说明。
