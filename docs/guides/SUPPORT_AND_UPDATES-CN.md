# 技术支持、故障处理与版本更新

[English](SUPPORT_AND_UPDATES.md) · [客户使用指南](README-CN.md)

## 找到负责团队

| 问题 | 首先联系 | 提供的信息 |
| --- | --- | --- |
| 无法登录或工作区受限 | 公司 IT 或权限管理员 | 环境、发生时间和页面错误；用户名通过获批渠道提供 |
| 来源缺失或数据过期 | 数据运营人员 | 来源、数据集或枢纽、交付期、最近成功运行及时间 |
| 价格、估值或分配结果有疑问 | 交易台或风险负责人，以及应用支持团队 | 结果编号、上下文、单位、假设和核对依据 |
| 页面、控件或设备适配问题 | 经 IT 服务台联系应用支持 | 版本、浏览器或设备、屏幕大小及方向、已脱敏截图 |
| 疑似安全事件 | 公司安全事件响应渠道 | 时间、受影响账户或服务、事件编号 |

[客户交接记录](CLIENT_ONBOARDING-CN.md)中应明确内部联系人、供应商升级渠道、服务时间、响应目标和恢复承诺。这些约定以实际支持安排为准。

## 先做针对性检查

| 情况 | 优先检查 |
| --- | --- |
| 服务可访问，但价格为空 | 行情连接或导入、授权、所选日期及首次采集结果 |
| ECB 或 ENTSOG 没有数据 | 来源启用状态、调度器及查询范围；ENTSOG 还需检查来源认证 |
| 已添加 Key，但数据未变化 | 当前生效的凭据来源、停用状态、连接器实现及来源激活 |
| 刷新后仍是旧页面 | 部署是否成功及线上提交编号；部署完成后重新加载 |
| 与另一套系统的数值不同 | 币种和单位、产品期限、来源时间、汇率定盘价及计算假设 |
| 手机上找不到控件 | 浏览器、屏幕尺寸和方向；将无法访问的控件作为功能问题反馈 |

## 提交可复现的问题

1. 说明正在完成的任务及触发问题的步骤。
2. 分别写出预期结果和实际结果。
3. 记录发生时间及其时区、环境和版本或构建信息。
4. 提供已有的事项、运行、来源编号，以及请求或关联编号。
5. 通过获批渠道附上相关诊断资料或截图。

打开“系统”>“设置”，使用“关于与诊断”获取版本及诊断信息。发送前检查附件，只分享调查所需内容；凭据和敏感交易信息使用公司指定的安全渠道传递。

页面无法打开时，提供网址路径、可见错误和时间。运营人员可据此或通过关联编号查找服务器事件。

## 按业务影响定级

| 级别 | 影响 | 初步处理 |
| --- | --- | --- |
| SEV1 | 广泛停机、疑似安全泄露或重大数据完整性事件 | 立即联系事件负责人，保留资料并确定控制措施 |
| SEV2 | 重要交易台任务受阻，且没有可靠替代方式 | 说明受影响人员或账簿及业务时限，升级处理 |
| SEV3 | 影响有限，存在可用替代方式 | 记录替代方法、影响范围和后续事项 |
| 改进建议 | 没有正在发生的事件，主要涉及易用性或能力提升 | 说明用户任务和预期收益 |

级别按实际影响确定。即使应用仍可访问，错误估值也可能比外观问题更紧急。运营恢复步骤见[事件响应手册](../operations/INCIDENT_RESPONSE.md)。

## 安装和更新

使用交付版本配套的安装包、校验和及安装指南。发布清单和验收材料标明已检查的构建及签名状态；安装包构建完成与已完成实际安装测试分别记录。

- **浏览器：**服务部署新构建成功后，重新加载页面。
- **Windows、Linux 桌面客户端：**由 IT 分发适用安装包，安排升级。当前桌面版本采用受管或手动更新。
- **服务器与数据库：**按版本要求执行迁移预检、备份和回退。应用代码回退与数据库变更恢复分别规划。

兼容性页面依据发布元数据、API 契约和最低客户端或服务器版本判断。出现阻断性不匹配时，使用交付方提供的配套版本处理。

参阅[更新政策](../release/UPDATE_POLICY.md)、[部署说明](../deployment/DEPLOYMENT_ROLES-CN.md)、[回退流程](../operations/RELEASE_ROLLBACK.md)。
