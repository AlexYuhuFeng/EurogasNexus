# UI Audit - 2026-08-31

## Scope

All 13 Web workspaces were rendered from the PostgreSQL-backed local runtime at
desktop (`1440 x 1000`) and mobile (`390 x 844`) viewports:

- Decision: Network, Scenario, Review
- Commercial: Resource Terms, Market, Capacity, Market Positioning
- Analytics: Strategy, Glossary
- Operations: Data Sources, Runtime, Settings, Manual

QA captures are local artifacts under `output/ui-audit/` and are intentionally
not release assets. The selected Image Gen 2 design reference is committed at
`docs/design/references/market-workspace-imagegen-2026-08-31.png`.

## Findings

1. `AppShell` mounted `NetworkWorkspace` for every page and hid it with CSS.
   Non-network pages therefore retained unnecessary map rendering, overlays,
   and focus targets.
2. The top-bar search only affects network nodes and lines but appeared on all
   13 workspaces, creating a visible control with no effect on 12 pages.
3. Every non-network page repeated the active page and runtime state in a large
   framed title card immediately below the global bar.
4. Adjacent tasks were only available through the full Tools menu, increasing
   navigation cost across Decision, Commercial, Analytics, and Operations flows.
5. The stylesheet contains multiple late responsive overrides. Future page
   redesigns should consume shared shell tokens and primitives rather than add
   page-specific positioning patches.
6. Strategy and Data Sources remain the longest surfaces and need later
   page-specific information-architecture work; this shell milestone does not
   claim those pages are fully redesigned.

## Implemented Milestone

- mount `NetworkWorkspace` only for the Network route and mount
  `WorkspaceRenderer` only for non-network routes;
- render the map search only on Network;
- replace the duplicate page/status card with an unframed identity band;
- add directly accessible sibling-page tabs for each workflow group;
- preserve compact, overflow-free mobile stacking;
- keep the full Tools menu as the global navigation entry point.

## Image Gen 2 Interpretation

The reference was generated from the running Market screen. Adopted principles:

- compact shell and immediate operational content;
- quiet separators and aligned dense rows;
- explicit live, runtime, source, and simulation semantics;
- restrained neutral palette with semantic status colors;
- no marketing hero, decorative illustration, nested cards, or oversized type.

The mockup contains illustrative values and must never be treated as market,
capacity, topology, contract, or portfolio data.

## Next UI Targets

1. Strategy: reduce the 15-panel, multi-thousand-pixel document into task-led
   views for setup, live shadow performance, comparison, and risk.
2. Data Sources and Runtime: consolidate duplicated health/status summaries and
   prioritize actionable exceptions.
3. Resource Terms: separate contract inventory, editor, validation, and
   resource-pool impact into stable responsive regions.
4. Network: continue verified-versus-indicative topology and coordinate QA.
