# Engineering Governance

This directory contains the lightweight change-governance documents for the
repository. The documents describe how to propose normative requirements and
how to plan an independently reviewable implementation slice.

- [RFC process](RFC_PROCESS.md) - when a change needs a normative proposal and
  how acceptance works.
- [RFC index](RFC_INDEX.md) - the public registry of accepted or active RFCs.
- [RFC template](RFC_TEMPLATE.md) - the starting structure for a proposal.
- [ExecPlan index](EXECPLAN_INDEX.md) - the current implementation-plan
  registry; it does not reproduce private or historical milestone records.
- [ExecPlan template](EXECPLAN_TEMPLATE.md) - the required implementation
  checklist for a bounded change.
- [Coding standards](CODING_STANDARDS.md) - code review and implementation
  conventions.

README files are descriptive navigation. Normative requirements use the key
words defined by RFC 2119 and RFC 8174 and live in the applicable policy,
contract, RFC, or ADR.
