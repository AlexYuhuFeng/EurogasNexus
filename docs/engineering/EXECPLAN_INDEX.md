# ExecPlan Index

ExecPlans are bounded implementation checklists for accepted requirements.
They are not architecture authority and must not be used to hide a required
RFC or ADR. Use [EXECPLAN_TEMPLATE.md](EXECPLAN_TEMPLATE.md) for a new plan.
