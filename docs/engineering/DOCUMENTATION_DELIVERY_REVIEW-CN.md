# 客户交付文档评审

[English](DOCUMENTATION_DELIVERY_REVIEW.md)

评审日期：2026 年 11 月 5 日。源码基线：`cad2f8f9`，软件包版本 0.7.0。
适用读者：文档、产品、实施和客户服务负责人。

## 评审结论

仓库已有较丰富的产品与运维资料，但客户使用层尚未形成完整、可靠的商业交接体系。主要差距在组织方式和操作说明的一致性，而不是文件数量。交易机构需要从具体任务快速找到准备条件、操作步骤、预期结果和支持渠道。

本次修订建立统一的客户使用层。实际安装验收、合同支持安排及发布审批，仍由对应交付记录落实。

## 问题与改进

| 发现 | 基线中的依据 | 本次处理 |
| --- | --- | --- |
| 客户首先进入工程资料目录 | 文档索引混合用户指南、架构计划和历史验收材料 | 将客户入口前置，专项技术内容保留在技术索引 |
| 入口和配置说明不一致 | 快速入门仍描述五个工作区；旧管理指南将数据源放在系统工作区 | 按当前六个工作区统一操作入口 |
| 服务可运行与数据可用混在一起 | 首次使用缺少数据样本核对 | 增加来源接通及来源到页面的核验 |
| 配置示例落后于实现 | 凭据规则变更后，主分支 CI 的生成模板检查失败 | 通过 PR #44 从配置登记重新生成两个发布示例 |
| 岗位指南偏重功能列表 | 部分指南缺少步骤及完成结果，并固定声明登录落点 | 改为任务、步骤、结果和异常处理 |
| 支持承诺缺少交付版本依据 | 浏览器、Python、服务器范围缺少对应验收矩阵，更新方式混为手动 | 改按发布材料确认平台，分别说明网页、桌面和 Render 更新 |
| 方法描述可能影响结果理解 | 曲线代码采用交付小时权重，风险指南写成按天加权 | 说明小时权重、头寸估值补用价格及估值例外 |
| 融资与币种说明落后于实现 | 旧组合说明沿用共享利率，并将不同币种统一视为未估值；现有代码已按合同利率计算并使用 ECB 换算 | 说明逐资源利率、默认规则、计息基准及缺失汇率的例外 |
| 中文客户资料不完整 | 岗位指南没有中文配套 | 增加按中文任务习惯编写的配套指南 |
| 客户操作文档夹杂开发回顾 | 图文索引列举历史缺陷并概括其修复情况 | 操作索引保留任务入口，历史说明转入工程记录 |

## 文档分层

- **客户使用层：**首次使用、岗位任务、数据解释、技术支持及客户交接。
- **专项参考层：**部署、单点登录、来源运营、API 和详细方法。
- **工程与发布记录：**架构决策、带日期的验收材料、发布就绪情况和开发历史。

统一客户入口为 `docs/guides/README.md` 及其中文配套文件。已有截图操作保留为参考。本次修改针对仓库文档，不改变应用内使用手册的实现，也不新增界面验收结论。

## 参考资料与采用原则

- [Bloomberg 专业服务支持](https://professional.bloomberg.com/support/)按产品、数据、软件更新和账户问题组织服务入口。本次据此明确支持分工和版本资料入口。
- [LSEG Workspace 学习资料](https://www.lseg.com/en/training/learning-centre/learning-paths/learning-paths-for-other/lseg-workspace)区分桌面、网页和移动使用。本次据此分别说明安装与更新方式。
- [Kpler 客户指南](https://help.kpler.com/en/articles/15451019-kpler-chartering-client-guide)将接入设置与实际任务联系起来；[方法资料库](https://help.kpler.com/en/collections/2123463-resources-methodology)单列来源和计算方法。本次据此区分操作指南与数值解释。
- [Apple 中国的设置说明](https://support.apple.com/zh-cn/guide/mac-help/mh15217/27/mac/27)采用直接的任务标题、带引号的界面名称及顺序操作。本次中文编辑采用类似的清楚表达，按任务组织内容。

这些公开资料用于研究结构和编辑方法，不代表本产品具有相同功能、服务承诺或认证。正文为本项目重新编写。

## 方法与集成的源码核对

工作区入口按 `productNavigation.ts` 核对；凭据及预览激活按统一凭据模块和启动程序核对；气日、曲线权重、合同币种换算和估值补用价格分别按日历、曲线及头寸实现核对。

融资说明核对资源池模型和应用组合代码，区分合同利率、情景默认利率，以及显式资源请求与已保存合同组合采用的计息基准。英文评审表列出具体源码文件。SDK 示例核对导入、请求地址、返回字段及命令行解析。

## 中英文核对方式

先完成英文事实基线，再按中文使用场景编辑。中文采用直接动作、中文界面名称及一致的交易术语，保留 API 名称、单位和标识。逐项核对权限、单位、操作步骤、完成结果、来源前提及异常处理，使中文读者无需打开英文正文也能完成任务。

## 发布前维护

确认文档对应的版本与构建，核对界面入口及来源示例，检查本地链接和语言配套，再完成代表性上线任务。更新截图时登记实际采集日期和构建信息。

支持联系人及时间、设备与浏览器版本、数据覆盖、恢复目标及验收责任人，由客户交接记录提供。[此前操作走查的原始说明](DOCUMENTATION_DELIVERY_REVIEW.md#earlier-walkthrough-record)保留在英文评审附录，供追溯。
