# 数据口径与计算说明

[English](DATA_STATUS_AND_PROVENANCE.md) · [客户使用指南](../guides/README-CN.md)

比较数值或调查系统间差异时，应同时核对来源、交付期、单位和时间。先确认口径，再判断差异。

## 先确认记录代表什么

| 项目 | 核对内容 |
| --- | --- |
| 枢纽、设施或账簿 | 商业地点和纳入范围是否一致 |
| 产品与交付期 | 日内、日前、周末、月度、季度、季节或日历年 |
| 单位与币种 | 价格、气量、速率和报告币种采用什么口径 |
| 观测适用时间 | 数值对应何时或哪个交付期间 |
| 发布或可获取时间 | 当时是否已经能够获得该信息 |
| 入库或读取时间 | 安装环境何时收到或读取这条记录 |
| 来源与方法 | 直接报价、评估值、计算值、导入记录或模拟数据 |

页面刚刷新，也可能读到较早的来源记录。实时推送连接表示应用组件间的传输状态，数据是否及时仍要看来源时间及其更新计划。

## 读懂数据状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 有效或最新 | 符合该来源配置的时效规则 | 检查交付期及来源，再作比较 |
| 延迟或过期 | 超过预期刷新时间或时效窗口 | 查看最近成功采集及供应商发布计划 |
| 缺失或不可用 | 所需记录缺失，或暂时无法读取 | 检查筛选条件、覆盖范围和来源结果 |
| 不预期有数据 | 按该来源的日历或频率，本期间不应产生记录 | 核对发布日历与更新频率 |
| 计算受阻 | 所需输入或条件尚未满足 | 打开列出的阻塞项并处理 |
| 模拟或 `_Sim` | 测试观测值 | 在测试范围内使用，导出示例时保留标识 |

查询成功但没有记录、查询失败，以及数值为零，是三种不同情况。读取失败后，页面可能保留上次成功记录，应同时查看其时间和失败提示。流量与容量合并视图则需要分别检查两个输入的状态。

## 区分数据来源

| 类型 | 示例 | 适用信息 |
| --- | --- | --- |
| 公开参考数据 | ECB | 已发布的参考汇率，与可成交的外汇买卖价不同 |
| 公开实物透明度数据 | ENTSOG | 指定范围内的网络、流量和容量观测 |
| 需要凭据的透明度数据 | GIE、ENTSO-E | 按各供应商要求接入的储气、LNG 或电力数据 |
| 授权市场数据 | 获授权的天然气报价、结算价、WMR/BFIX 导出 | 公司获准使用的具体数据集 |
| 运营记录 | 合同、交易导入、费率 | 该环境中提供或维护的信息 |
| 测试数据 | 模拟来源 | 操作示例和测试情景 |

来源目录中的条目不等于正在运行的连接器。ENTSOG 无需 API Key，但仍有查询范围及来源认证步骤。接入流程见[管理与数据运营](../guides/ADMIN_AND_OPERATIONS-CN.md)。

## 统一价格、气量和汇率口径

NBP 常用 **p/th** 报价，欧洲大陆枢纽常用 **EUR/MWh**。**MWh** 表示能量，**MW** 表示功率，**MWh/d** 表示每日能量数量或速率口径。货币金额、年化百分比和每日现金金额也应分开阅读。

枢纽价差需要相同的交付期、价格类型、币种和单位。例如，可比中间价为 EUR 30/MWh 和 EUR 29/MWh 时，差额为 EUR 1/MWh。这是算术示例，不是市场报价。

换算时，查看汇率来源、价值日期及平均期间。ECB 参考汇率、WM/Reuters 定盘价和 Bloomberg BFIX 属于不同基准，其标识及导入方式见[汇率定盘价](../operations/FX_FIXINGS.md)。

包括 EEX TTF NGP 在内的成交量加权参考指数，与可成交的买卖报价具有不同含义。

## 按气日核对时间

当前 `EU-CAM-UTC-2025` 日历以中欧当地时间 06:00 为气日起点：冬令时对应 UTC 05:00，夏令时对应 UTC 04:00。夏令时切换的气日可能包含 23 或 25 个交付小时。

保存日期分析时，同时保留日历标识。历史记录可能使用此前冻结的日历版本。气日标签不一定表示 UTC 零点至零点，应按页面的期间边界核对小时速率及每日气量。

## 计算口径

| 结果 | 需要查看的依据 |
| --- | --- |
| 月度曲线 | 优先采用月度报价，再以交付小时权重分配较长产品的剩余价值 |
| 头寸估值价格 | 各月的曲线方法；未覆盖月份可能采用标明的最近收盘价平价沿用 |
| 参考性 VaR | 已纳入头寸的历史价格变动，以及页面显示的期限、置信水平和历史范围 |
| 资源池分配 | 已保存资源与销售选项、价格成本、容量和使用权约束，以及各合同利率和情景默认值 |
| 资源池提前回款价值 | 依据资源利率、计息基准和实际收付款账期计算的单利时间收益 |
| 回测 | 冻结策略及运行编号、数据覆盖、信息可获取时间截点和成本 |
| 研究数据集 | 已登记特征与目标、观测类型、预测批次和时点可用规则 |

阅读汇总时，同步检查未估值交易腿、缺失汇率、平价沿用、冲突报价和被排除的观测。按交易台实际问题确认模型覆盖范围；风险指标之间承担不同的分析任务。

## 资源池的融资计算

每段分配优先使用资源自身记录的年化融资利率；利率缺失时使用情景默认值。结果会标明采用的利率及来源。每 MWh 的提前回款价值按下式计算：

```text
有效天数 = max(上游付款账期天数 − 实际销售回款账期天数, 0)
成本基数 = 合同成本 + 可变成本 + 燃料损耗成本
提前回款价值 = round(成本基数 × 年化利率百分数 / 100 × 有效天数 / 年天数, 4)
```

销售回款账期优先采用资源的覆盖值，否则采用销售选项中已声明的账期。两项账期都须已知。没有正向回款时间优势时，该项收益为零，其他融资现金成本另行评估。

资源模型默认采用单利 ACT/365F；显式资源请求也支持 ACT/360。当前已保存合同的资源组合沿用资源默认计息基准。检查结果中的利率、来源和计息基准，区分已记录的 0% 与未填写利率。

独立的带日期现金流估值引擎及其适配接口见[现金估值说明](../architecture/CASH_VALUATION_CAPABILITY.md)。

## 留存分析依据

在交易台复核记录中保存事项、运行或快照编号，以及相关来源、输入期间、假设、警告和允许导出的材料。发现数值异常时，按[支持流程](../guides/SUPPORT_AND_UPDATES-CN.md)提供同一口径下可复现的比较。
