# Quick Start

Eurogas Nexus is a decision-support workspace for European gas professionals.
It does not execute trades, orders, or nominations. Every result is indicative
and requires human review.

## Open the product

1. Browser: open the Web workspace. Desktop: install the Windows/Linux client.
2. Configure the backend API URL in Settings if it is not preconfigured. It
   must be `/api` or an HTTPS URL ending in `/api`.
3. Verify the Runtime status in the top bar and About & Diagnostics in
   Settings.

## The five workspaces

- **Market**: hub prices, spreads, network/capacity context, and current
  opportunity feed. Select gas day, product, and hub in the top context bar.
- **Portfolio**: resource terms, routes, exposure, and optimizer handoffs.
- **Strategy Lab**: design, freeze, backtest, compare, and shadow monitoring
  of research strategies.
- **Decision Center**: scenario, optimizer results, and human review.
- **System**: data sources, runtime health, settings, manual, and access.

## Read every number with its context

Before relying on a number, check:

- gas day/product shown in the top context bar;
- source and freshness shown next to the value;
- assumptions and warnings in the evidence panel;
- `research_only` and `human_review_required` badges.

## First professional tasks

1. Market: choose a hub, inspect spread, open a route in Scenario.
2. Portfolio: inspect resource, run optimizer, open Review.
3. Strategy Lab: create draft, resolve blockers, freeze, run backtest.
