# 组合比较与头寸复核

[English](PORTFOLIO_WORKFLOW.md) · [交易员指南](../guides/TRADER-CN.md)

## 比较资源和路径

1. 打开“组合”，查看已保存资源的气量、综合成本和使用权。
2. 打开路径视图，对比可行方案，并查看受阻方案的原因。
3. 将路径带入“决策中心”的情景分析。方案对比采用已保存的资源池数据，包括资源气量及成本、销售价格、路径成本及容量、各数值的币种与单位，以及已保存的气年。分别核对这一保存口径和情景面板中的临时修改。
4. 在优化页运行资源池优化。各资源优先使用自己的合同融资利率；未记录利率时使用情景默认值。界面默认值取自第一份已保存上游合同，缺失时取草稿值。利率为年化百分数。逐项检查分配结果的利率、来源（`contract` 或 `scenario_default`）和计息基准。
5. 查看已分配及未分配气量、起约束作用的条件和损益归因。
6. 打开复核页，检查假设及来源，记录获授权的复核结果。

分配引擎对已声明的输入和约束采用最小费用流计算。[数据说明](DATA_STATUS_AND_PROVENANCE-CN.md#资源池的融资计算)列出收付款时间收益的单利公式，以及默认利率、ACT/365F 和 ACT/360 的使用口径。

## 复核头寸阶梯

在“组合”的敞口视图中，将实物合同和已成交金融交易放在一起查看。

| 项目 | 含义 |
| --- | --- |
| 行 | 按交付月列示，再按枢纽细分 |
| 实物 | 有效已保存合同在其气年窗口内的每日合同气量及交付枢纽 |
| 金融 | 按交付气日分配的已成交数量，买入为多头、卖出为空头 |
| 净头寸与套保 | 净多空及交易对实物头寸的对冲比例 |
| 估值价格 | 枢纽月度曲线及推导方法，未覆盖月份采用最近收盘价平价沿用 |
| 汇总 | 实物、金融、净头寸、套保指标、盯市估值及历史价格 VaR |

合同价格保留记录的币种。组合估值使用可用的 ECB 参考汇率将合同价格转换为枢纽币种；缺少换算条件时，结果列明估值例外。报告币种汇总同样依赖相应汇率。核对总额前，先检查未估值交易腿、汇率警告和估值价格方法。

页面的一日 95% 历史 VaR 描述已纳入未平头寸的价格变动。气量、基差、形状和信用敞口分别复核。比较时，使用选定账簿范围及公司已核对的头寸记录。

控制与复核记录见[风险与财务指南](../guides/RISK_AND_FINANCE-CN.md)。
