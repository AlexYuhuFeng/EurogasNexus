# 首次登录与基础检查

[English](QUICK_START.md) · [客户使用指南](../guides/README-CN.md)

完成本节后，你可以登录工作区、确认分析口径，并核对一条已有数据。

## 准备好登录信息

向 IT 获取工作区网址或获批的桌面安装包、登录方式以及内部支持联系人。请交易台负责人指定首次核对所用的账簿、枢纽和交付期。所需数据源由管理员配置。

## 登录并设置显示偏好

1. 在浏览器中打开工作区，或启动桌面客户端。
2. 使用 IT 提供的登录方式。公司单点登录账户与独立测试账户分别用于对应环境。
3. 使用受管桌面客户端时，检查预配置的服务地址。如需手动填写，使用 IT 提供、以 `/api` 结尾的 HTTPS API 地址。
4. 打开“系统”>“设置”，选择语言、外观和常用市场视图。

**完成检查：**账户菜单显示你的姓名，所分配的工作区能够打开。如果已登录但某个工作区受限，请 IT 核对角色和数据范围。

每个安装环境使用该环境单独发放的账户。

## 核对第一条市场数据

1. 打开“市场”>“曲线与价差”。
2. 选择本次任务的气日、交付产品和枢纽。
3. 查看报价的来源、单位和时间戳，再比较同一口径的买卖价及中间价。
4. 需要实物背景时打开“容量与事件”；需要查看位置时打开“网络”。
5. 将一条显示记录与交易台使用的原始来源或导入文件核对。

**完成检查：**交付期和单位与你准备分析的问题一致。服务连接正常但没有报价时，应检查行情接入或导入结果；连接状态不能替代数据检查。

## 开始日常工作

- [交易员](../guides/TRADER-CN.md)：市场、资源、路径和头寸。
- [研究与量化](../guides/ANALYST_QUANT-CN.md)：价差、策略运行和数据集。
- [风险与财务](../guides/RISK_AND_FINANCE-CN.md)：敞口、估值和限额。
- [管理与数据运营](../guides/ADMIN_AND_OPERATIONS-CN.md)：账户及数据接入。

## 如果检查未通过

| 看到的情况 | 处理方式 |
| --- | --- |
| 无法登录 | 核对环境和登录方式，将发生时间及页面错误交给 IT |
| 工作区受限 | 按公司权限流程申请相应角色或数据范围 |
| 没有记录 | 先检查日期和筛选条件，再确认数据源是否已首次采集成功 |
| 时间戳较旧 | 查看数据时效、发布计划及最近一次采集结果 |
| 页面被裁切或控件无法打开 | 记录设备、浏览器、屏幕方向并截屏，按[支持流程](../guides/SUPPORT_AND_UPDATES-CN.md)反馈 |
