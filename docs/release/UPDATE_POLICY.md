# Desktop Update Policy

## Decision for CR-12

The Tauri v2 updater plugin is **not shipped** in this release. Auto-update
infrastructure requires a private updater signing key, public endpoint hosting,
and an update acceptance environment; CR-12 does not fabricate those external
assets.

Workstation update is therefore conservative and managed:

- Default policy: **MANUAL** — the deployment operator distributes the signed
  installer plus `SHA256SUMS`, `release-manifest.json`, and the install guide.
- Managed/offline: **DISABLED** by default. No background downloader exists, so
  a restricted workstation never performs an undisclosed update.
- No forced update or silent restart is possible in this build.

## Conceptual future modes

When an updater is eventually authorized, it must support `NOTIFY`, `MANUAL`,
and `DISABLED` deployment policies, and later `ADMIN_MANAGED`. It must never
force a restart during an active analytical session and must never offer a
preview endpoint to a stable client.

## Updater signing is separate

Tauri updater signatures (`.sig` files generated by `tauri signer generate`
and `createUpdaterArtifacts`) are a separate trust mechanism from Windows
Authenticode. Both the private updater key and code-signing credentials remain
externally owned and are never committed. The public updater key would be
packaged only when the updater actually ships.

## Compatibility before update

A future updater must evaluate client version, server version, `api-contract/v1`,
and minimum supported versions before offering an update. The current manual
path achieves the same guarantee through `/api/runtime/release` and the client
compatibility blocking screen.

## Offline/managed distribution

1. Obtain the signed installer and `SHA256SUMS` from the release operator.
2. Verify `sha256sum -c SHA256SUMS` (or `Get-FileHash` on Windows).
3. Install through the managed software-distribution tool of record.
4. Record version/channel/commit and the deployment config
   (`%ProgramData%\Eurogas Nexus\Client\deployment.json`).
