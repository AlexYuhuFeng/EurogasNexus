# 0.8.0 engineering log

Engineering notes for 0.8.0, for reviewers and auditors. The user-facing summary is in
[CHANGELOG.md](../../../CHANGELOG.md).

## Schema

- `0058_contract_financing_tranches`: a nullable JSON column on the upstream contract for
  funding segments (#14). Contract revision schema v4 carries the tranches as canonical exact
  decimals. v4 is written only when tranches are present, so v1–v3 revisions and their
  content hashes are unchanged. The edit token covers the new column.
- `0057_contract_price_currency` (in this release line): the price currency of a contract
  (GBP, EUR, USD), revision schema v3.

## API

Census 231 paths / 249 operations (from 231 / 248). Changes:

- `POST /api/market/nwe-balance` (NW Europe balance forecast, merged from the functional
  branch).
- `GET /api/sources`:
  - Every row carries `integration`: `api`, `file_import`, `template` or `model_service`.
  - The model-service row carries `model_service` `{provider_name, model, host}` from
    `EUROGAS_NEXUS_LLM_*`. The key and the URL path are never included (test:
    `tests/api/test_sources_api.py::test_model_service_names_the_configured_endpoint_without_the_key`).
- Contract write routes accept `financing_tranches`, with presence semantics: an absent field
  keeps the stored tranches, `[]` clears them. Invalid input returns `financing_tranches_invalid`.
- Credentials: `effective_source` per provider (`disabled`, `environment`, `key_file`,
  `store`, `none`). The precedence is in `security/provider_credentials.py`.

## Client architecture

- **View registry** (`app/navigation/viewRegistry.ts`, #31). Every page's sub-view and owned
  object parameters are declared once. `useUrlView` pushes history and `useUrlObject` replaces
  it. Unknown values fall back to the page default. Foreign object parameters are cleared on a
  page change. The command palette is generated from the registry.
- **Information architecture** (#30, #36). Research = strategy + research data + agent research
  (commercial boundary). Help & Settings = settings, manual, glossary. Page ids are unchanged,
  so old links resolve. A nested `WorkspaceHeader` under the shell title renders tabs and the
  primary action with a visually hidden h2.
- **Connectors view** (`app/model/connectorCatalogModel.ts`, #26, #33). One rule groups every
  source as attention, connected or available. The top-bar issue count, the Sources metric strip
  and Runtime release checks all use it. An optional provider nobody set up is never an issue.
- **Contract chain** (`app/model/contractChainModel.ts`, #32). Drafts, unsaved edits and stale
  pool runs never count as done.
- **Adaptive shell** (`app/shell/useShellLayout.ts`, `docs/product/ADAPTIVE_CLIENT.md`, #40).
  `data-width-class` and `data-pointer` on `<html>`. At compact width the bar is one row and a
  drawer is portalled to `<body>`, because the header's backdrop filter would contain a fixed
  child. Map layers go in a panel and admin forms in one column.
- **EmptyState** (`components/ui/EmptyState.tsx`, #27). One reason and one next step. It never
  draws a value.

## Acceptance

- Browser acceptance (EN/ZH; 1440, 1920, 390 px) declares scoped read-to-render contracts for
  contracts, glossary, orders, review, runtime and sources. Runtime gained one because its
  default view moved to Health. The narrow-viewport journey now exercises the compact drawer
  (closed by default, opens, shows the context controls, Escape returns focus). The displayed
  Active Context is read from `[data-context-gas-day]`, whichever element carries it.
- macOS jobs run on `macos-15`. GitHub no longer serves `macos-14`.

## Decisions worth knowing

- **No dataset-snapshot lineage on strategy runs yet** (#32). `StrategyRunManifest` has
  `dataset_snapshot_id`, but the backtest reads market history directly. A UI hand-off from a
  snapshot to a backtest would record lineage that is not true, so it was not added.
- **Connectors C1/C2 (manifests, entry-point plugins) are not in this release.** The Connectors
  view is derived from the existing registries. The manifest refactor must keep the registries
  and APIs byte-identical and lands separately (`docs/product/CONNECTORS.md`).
