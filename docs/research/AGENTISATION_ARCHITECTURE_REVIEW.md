# Independent agentisation architecture review

**Recommendation.** Keep the market and portfolio control loop deterministic. Extend the existing research workflow only when an unfamiliar investigation benefits from selecting the next question dynamically. The first experiment shows that provenance and refusal can be added around existing engines at sub-millisecond in-process cost. It provides no evidence of model-driven commercial uplift. Test any agent against both direct engine calls and the best fixed workflow on the same frozen information.

## Suitability by workflow

| Area | Recommendation | Value, maturity and cost |
| --- | --- | --- |
| Market intelligence | LLM_ASSISTED | Extract candidate entities, event types and questions from comments and notices. Resolve canonical identities, timestamps and approved sources before linking exposure. Measure verified event-to-book recall and false alarms. Keep structured feed parsing and trigger thresholds deterministic. |
| Portfolio surveillance | DETERMINISTIC_WORKFLOW | Use materiality limits, row scope, dependency keys and attributed alert rules on committed inputs. Permit a separate analyst investigation for unusual correlated risks. Establish event freshness and cancellation before adding model latency. |
| LNG cargo-to-market | DETERMINISTIC_WORKFLOW | Check ETA, rights, storage, Send-out, transportation, sales and hedges against a consistent snapshot. For an unfamiliar disruption, an opt-in research planner might propose alternate scenarios. Economic ranking belongs to the existing solver and quote/cost services. |
| Multi-cargo and resource pool | DETERMINISTIC_ONLY | Joint constraints prevent two proposals from claiming the same berth, day, Send-out or pipeline headroom. Candidate generation may later use AI, with authoritative feasibility checked on every candidate. A separate persistent agent per cargo increases conflicting assumptions and coordination cost. |
| Contract intelligence | LLM_ASSISTED | Draft clause candidates for MSPA, confirmation, EFET, terminal, tariff and TSO documents. Seek page/span, amendment precedence, effective date and reviewer approval. Material savings are in evidence retrieval and review time. Approved computational terms remain controlled. |
| Risk management | DETERMINISTIC_ONLY | Position, credit, liquidity, stress and P&L metrics demand reproducibility. The current Risk Challenger should remain a deterministic gate. Optional language assistance can suggest review questions outside the gates. |
| Research and strategy | AGENT_ORCHESTRATED | Only a bounded challenger in the existing orchestrator, after it beats fixed-plan B on unfamiliar questions. Start with validated next-step proposals over read-only features and scenarios, using the same research budget and deterministic validation. Cost includes adjudication, provider latency and missing-data fallback. |
| Data quality and operations | DETERMINISTIC_WORKFLOW | Timeouts, freshness, dimensions, unit checks and reconciliation are automated rules. Use optional constrained incident summarisation for unfamiliar multi-source failures after outcomes are captured. |
| Execution coordination | DETERMINISTIC_WORKFLOW | Prepare a versioned human-review package, monitor status and ingest outcomes. Booking, nominations and confirmations remain with authorised external systems. |
| Reporting and knowledge | LLM_ASSISTED | Render routine numbers from templates. A single prompt may help answer a scoped question over vetted facts. Require verifiable claim-to-field links and deterministic fallback. |
| Autonomous cross-book agents | DEFER | Require proved incremental value, tenant-scoped identity and independent evaluation before any wider exploration. |

## A, B and C compared

| Question | A — engine | B — fixed workflow | C — governed planning |
| --- | --- | --- | --- |
| Accuracy and reliability | Best for explicit inputs and calculable questions. Reproducible within a version and snapshot. | Adds evidence resolution, refusal, fallback and dependency trace around the same calculation. | Can widen search coverage. New error modes include irrelevant tools, ungrounded links and silent omissions. Cite a proposition and verify its effective date, scope and units separately. |
| Complexity | Few failure points and simple latency accounting. | Adds orchestration and state transitions where a task genuinely spans steps. | Adds model lifecycle, prompt versions, policy controls, spend, adjudication and nondeterministic behavior. |
| Responsiveness | Fast first response for units, tariff and single defined reads. | Event-triggered checks can publish an initial answer before later scenario solves. | A deadline-bounded parallel investigation can help a human on rare novel tasks. On the market tick path it adds serial waits with no demonstrated value. |
| Economics | Known scenarios and rankable alternatives with reproducible P&L. | Better repeatability and reduced manual handoff. | Target overlooked alternatives and verified analyst time saved. Count false recommendations, extra review and model cost as negative value. |
| Governance | Input versions and calculation manifests support reconstruction. | Decision, dependency and authorization trace explains every stage. | Reconstruct the executed evidence and tool path rather than expecting identical model text. Require per-tool scope and restricted evidence routing. |

Typical defaults are A for conversions and simple pricing, B for ETA, risk checks and multi-cargo decision preparation, and a trial of C for a novel market/contract investigation whose next step cannot be written cheaply as a rule. The selected prototype exercises A and B with identical inputs and engines. It uses the limited additive scenario capability to isolate workflow overhead from database and solver cost.

## Architectural stability criterion

Judge A, B and C on lifecycle cost as well as initial latency. Stable identities, temporal cutoffs, portable event and export formats and migration compatibility lower the cost of all three paths. Activate infrastructure only where an identified consumer and deployment evidence justify the maintenance burden. The proposal records an 18–36 month technology decision, licensing considerations and rollback posture for each candidate.
